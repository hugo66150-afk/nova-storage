==============================================
 NOVA STORAGE — Guide de démarrage
 Version 1.3.0
==============================================

Nova Storage est un gestionnaire intelligent du stockage Windows.
Il fonctionne entièrement en local : aucune donnée de fichiers
ne quitte votre ordinateur.

--------------------------------------------------------------
 1. COMMENT INSTALLER
--------------------------------------------------------------

  - Ouvrez le fichier  Nova-Storage-Setup-x64.exe
  - Suivez les étapes de l'installateur (vous pouvez choisir le
    dossier d'installation, le raccourci Bureau et le raccourci
    du Menu Démarrer).
  - L'installation ne nécessite aucune connexion Internet.

  MISES À JOUR AUTOMATIQUES :
  - L'application vérifie les mises à jour au démarrage et les
    installe toute seule par-dessus la version existante, sans
    re-téléchargement manuel.

--------------------------------------------------------------
 2. COMMENT LANCER NOVA STORAGE
--------------------------------------------------------------

  - Double-cliquez sur le raccourci « Nova Storage » créé sur
    votre Bureau ou dans le Menu Démarrer.
  - Au premier lancement, lancez une analyse de vos disques
    depuis la page « Analyser ».

  NOVA FREE — GRATUIT, POUR TOUJOURS
  L'analyse, la visualisation, le nettoyage manuel, Nova Coach,
  la quarantaine et le Gardien essentiel restent gratuits.

  NOVA PRO — ACHAT UNIQUE · 9,97 €
  Nova AutoClean (maintenance automatique), l'automatisation par
  règles, le Gardien Pro et les prévisions de stockage sont proposés
  avec Nova Pro. Toutes ces fonctions sont regroupées dans la
  catégorie « Nova Pro ✦ » de la barre latérale.
  Chaque nouvel utilisateur peut découvrir Nova Pro gratuitement
  pendant 7 jours, sans carte bancaire, depuis l'application.
  L'achat s'effectue en toute sécurité chez Lemon Squeezy
  (checkout officiel, aucune donnée bancaire ne passe par Nova).

--------------------------------------------------------------
 3. OÙ TROUVER L'APPLICATION
--------------------------------------------------------------

  - Installation classique :
      %LOCALAPPDATA%\Programs\Nova Storage\
    (ou le dossier que vous avez choisi à l'installation)
  - Vos données (base locale, préférences) :
      %APPDATA%\Nova Storage\

--------------------------------------------------------------
 4. COMMENT DÉSINSTALLER
--------------------------------------------------------------

  - Windows > Paramètres > Applications > Applications installées
    > Nova Storage > Désinstaller
  - ou : Panneau de configuration > Programmes et fonctionnalités
    > Nova Storage > Désinstaller

  IMPORTANT : la désinstallation supprime le programme mais
  conserve vos données locales (%APPDATA%\Nova Storage),
  pour ne jamais perdre vos analyses et préférences.

--------------------------------------------------------------
 5. AIDE ET SUPPORT
--------------------------------------------------------------

  - L'application affiche ses états et messages dans l'interface.
  - Votre statut Nova (Free / Essai / Pro) est visible en permanence
    dans la barre de titre (badge FREE / PRO · ESSAI / PRO) et en
    détail dans les Paramètres, section « Nova Pro ».
  - Version : 1.3.0 — consultez RELEASE_NOTES.txt pour le détail
    de cette version.

--------------------------------------------------------------
 NOVA STORAGE — LOCAL-FIRST
--------------------------------------------------------------

Toutes les analyses de fichiers restent sur votre ordinateur.
Aucune télémétrie, aucune collecte, aucun envoi de données.
