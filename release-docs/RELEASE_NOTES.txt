==============================================
 NOVA STORAGE — Notes de version
 Version 1.2.0
==============================================

NOUVEAUTÉS DE LA VERSION 1.2.0
------------------------------

  - Publication automatisée : la commande `npm run release -- X.Y.Z`
    prépare (bump, typecheck, tests), build, vérifie les artefacts,
    régénère le livrable, publie le site et crée la GitHub Release
    en une seule commande.
  - Mise à jour automatique validée de bout en bout en production :
    une nouvelle GitHub Release est détectée au démarrage, téléchargée
    en arrière-plan et installée silencieusement à la fermeture de
    l'application.
  - Canal de mise à jour définitif : GitHub Releases (repo public
    hugo66150-afk/nova-storage) — plus aucun serveur à héberger.

CONTENU DE CETTE VERSION
------------------------

Première version distribuable de Nova Storage. Cette version
finalise le socle fonctionnel de l'application et intègre le
modèle Nova Free / Nova Pro.

Fonctionnalités principales :

  - Analyse complète du stockage Windows
      • Analyse complète, rapide ou personnalisée (multi-disques)
      • Scan exécuté en arrière-plan (worker dédié), interface fluide
      • Progression, pause, reprise et annulation
      • Classification automatique (catégories, gros fichiers,
        fichiers anciens, téléchargements, doublons par contenu)

  - Nova Coach
      • Recommandations classées par gain d'espace
      • Explications de chaque suggestion et actions sécurisées

  - Gardien du stockage
      • Surveillance en arrière-plan des disques (même application
        fermée, via le systray)
      • Seuils d'alerte configurables (ex. 80 % / 90 % / 95 %)
      • Notifications Windows et résumé hebdomadaire (gratuits)
      • Prévisions de remplissage (Nova Pro)
      • Prévisions avancées (Nova Pro) : dates estimées des seuils
        80 / 90 / 95 % et de saturation, calculées sur l'historique
        réel d'évolution du stockage

  - Catégorie « Nova Pro ✦ » dans la sidebar
      • Toutes les fonctions Pro regroupées et visibles immédiatement
        (même en Free) : Nova Pro, AutoClean, Automatisation,
        Gardien Pro, Prévisions — chacune avec un badge PRO doré

  - Hub Nova Pro
      • Page d'accueil de l'offre : statut de licence clair
        (Free / Essai / Pro), prix unique 9,97 €, essai 7 jours,
        cartes des fonctionnalités premium, état honnête du store

  - Nova AutoClean (Nova Pro)
      • Maintenance automatique : fichiers temporaires, téléchargements
        anciens, gros fichiers — en quarantaine restaurable ou corbeille
      • Déclencheurs : quotidien, hebdomadaire, au démarrage, ou quand
        un disque dépasse un seuil (80 / 85 / 90 %)
      • Simulation complète avant activation (dry-run), confirmation,
        exécution « maintenant », historique détaillé
      • Réutilise le moteur de règles existant : protections, exclusions
        et quarantaine appliquées automatiquement

  - Gardien Pro (Nova Pro)
      • Détection de croissance anormale (rythme récent vs moyenne)
      • Causes principales par catégorie (dernière analyse)
      • Bascule directe vers Nova AutoClean pour passer à l'action

  - Prévisions (Nova Pro)
      • Page dédiée : tendance, rythme de remplissage, saturation
        estimée, seuils 80 / 90 / 95 % et saturation complète
      • « Pas assez de données » plutôt qu'une fausse précision

  - Automatisation (Nova Pro)
      • Éditeur de règles complet : créer, modifier, supprimer,
        dupliquer, activer / désactiver une règle
      • Conditions SI combinables (taille, ancienneté, extension,
        dossier, emplacement, catégorie) et actions ALORS
        (corbeille, quarantaine)
      • Mode simulation (dry-run) : aperçu du nombre de fichiers
        concernés, de l'espace libérable et des avertissements,
        sans aucun effet réel — avant d'activer une règle
      • Planification par règle : une fois, horaire, quotidien,
        hebdomadaire ou mensuel, avec prochaine / dernière exécution
      • Historique d'exécution détaillé (fichiers, espace, statut)

  - Nettoyage sécurisé
      • Corbeille Windows ou suppression définitive
      • Quarantaine restaurable (avec restauration vers l'emplacement
        d'origine)
      • Exclusions utilisateur, éléments protégés, niveaux de confiance

  - Applications et jeux
      • Détection des applications installées, désinstallation
        sécurisée avec sauvegarde .reg et nettoyage des restes
      • Détection des jeux Steam, Epic, Battle.net, GOG, Riot,
        Ubisoft, EA et autres (Valorant, League of Legends…) via
        les bibliothèques, les dossiers de launchers et le registre
        Windows

  - Explorateur de fichiers intégré
      • Navigation par dossiers avec tailles, tri et recherche

  - Confidentialité LOCAL-FIRST
      • Aucune télémétrie, aucune collecte, aucune donnée envoyée
      • Base locale SQLite dans le profil utilisateur

MODÈLE NOVA FREE / NOVA PRO
---------------------------

  NOVA FREE — 0 €, pour toujours
    Analyse, visualisation, catégories, gros fichiers, doublons,
    applications, jeux, nettoyage manuel, corbeille, quarantaine,
    historique, Nova Coach et Gardien essentiel.

  NOVA PRO — achat unique · 9,97 € TTC
    Automatisation par règles, maintenance planifiée et prévisions
    avancées du Gardien. Le paiement (Lemon Squeezy) sera activé
    lors de la mise en ligne de la boutique.

  ESSAI GRATUIT DE 7 JOURS
    Chaque nouvel utilisateur peut activer 7 jours de Nova Pro sans
    carte bancaire, depuis l'application. Essai unique : il ne
    recommence pas après désinstallation/réinstallation. À la fin
    de l'essai, Nova revient automatiquement à Free — aucune donnée
    n'est supprimée, les règles restent sauvegardées.

  UX STATUT NOVA (barre de titre et Paramètres)
    Un badge de statut permanent dans la barre de titre indique
    l'état exact : « FREE » (discret), « PRO · ESSAI » (violet,
    jamais confondu avec un achat) ou « PRO » (doré, glow premium).
    Un clic ouvre Paramètres → Nova Pro. Le Dashboard rappelle
    sobrement la fin d'essai quelques jours avant l'expiration.
    Le statut affiché provient exclusivement de la source de vérité
    calculée côté MAIN : aucune page ouverte ni checkout ne peut
    débloquer l'affichage Pro.

Sécurité :
  - contextIsolation, sandbox et nodeIntegration désactivé
  - API preload minimale et typée (contextBridge)
  - Politique de sécurité du contenu (CSP) stricte
  - Validation des chemins et des commandes système
  - Statut de licence calculé côté MAIN (jamais stocké tel quel) ;
    les protections Pro sont appliquées dans le processus principal
  - Aucune donnée ne quitte l'ordinateur
